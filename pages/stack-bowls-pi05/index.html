04 / Debugging

先解决环境，再谈结果。

本周最大的工程工作不是改模型，而是定位依赖环境和显存配置，让实验真正越过启动阶段。

问题：依赖被 OpenPI 覆盖

install.sh 先安装 XPolicyLab，随后 uv run 按 OpenPI 的 pyproject.toml 同步依赖，把 XPolicyLab 需要的 h5py 等包清掉，直到运行时才暴露导入错误。

修复：最后单独安装 XPolicyLab

在 OpenPI 虚拟环境中重新执行 XPolicyLab editable install，并取消末尾的 uv run 环境重同步；随后通过 h5py、YAML 和模型模块导入验证。

问题：JAX 显存分配失败

初始配置 XLA_PYTHON_CLIENT_MEM_FRACTION=0.3，在目标 L40S 可用显存不足时，JAX 申请约 2.25 GiB 失败，Policy Server 未能打开端口。

修复：调整显存上限并避开繁忙 GPU

核对 GPU UUID、进程和剩余显存后，将策略服务和 Isaac 环境分配到可用 GPU，并将比例调整为 0.8，最终成功启动并完成评测。
