TacJev 的角色与当前合同

2026-10-25 按当前工作树一方源码核验。以下是项目事实；Tactile-ETA 作者没有提出 TacJev 蒸馏。

输入和输出

  • 当前首版输入：scene_rgb、wrist_rgb、tactile_mosaic_rgb 三图，之后是完整任务及最近最多五个已执行 MV_* token，新的在前。触觉拼图左指在上、右指在下。GRASP、RELEASE、DONE 不入移动历史。
  • 精确末端位姿、关节量、物体/目标真值与接触力用于控制、审计或判分，不能默认加入这一版学生输入。
  • 输出九选一：MV_FWD、MV_BACK、MV_LEFT、MV_RIGHT、MV_UP、MV_DOWN、GRASP、RELEASE、DONE。Arena profile 六方向对应基座 +X/-X/+Y/-Y/+Z/-Z；解释器保持向下姿态，九词表不含旋转或力目标。
  • DONE 结束决策，不产生物理帧，也不宣告原生任务成功。决策 token、控制帧和物理子步分别计数。

成熟度边界

已实现在线教师请求、单 token 解析、决策前证据及独立发布门禁；客户端没有提供教师 hidden states 或完整九类 logits。已有连续动作 BC 冒烟不是 TacJev。已核查代码没有完整九类 TacJev 训练、checkpoint 服务和原生成功闭环证据。教师经验输入亦未接通；TactileExperience.v1 是拟议派生制品名。

建议先做经验制品与教师上下文 A/B，再以合格动作标签训练学生。所有蒸馏方案都属于工程推断，需要新的输入版本、训练与持出原生评测。
