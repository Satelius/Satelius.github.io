### 首批实施顺序与交接件

1. **核对现有入口与教师服务**：复用 Arena 原生运行、TacClaw 记录和 DataEngine 组件，确认 Sub2API 实际型号、输入能力及合法单 token 返回；保留失败预检证据。当前只读查询超时是服务未确认，不代表机器人任务失败。
2. **验证模型视角与动作语义**：确认实际场景图覆盖工作区和原生采样目标，腕部与双指触觉输入正确；校准九 token 的轴向、步长、抓放保持与固定朝下姿态。冻结观测和解释器版本，不借物体真值替教师决定动作。
3. **串成可重跑采集入口**：声明任务、开局、教师与解释器版本、预算和输出目录；按“决策前观测—教师 token—解释器控制帧区间”执行并记录。验证网络等待时物理状态/目标计时器不前进、每个 token 只执行一次；全部实际尝试计入相应预算。
4. **采集并由 Agent 选择下一步**：保留每次尝试及原生任务/数据门禁结果。Agent 引用真实问题证据，先记录假设、允许范围内的调整及预计变化，再运行调整方案；当前候选配置、相机或解释器修复按版本和基线规则处理。
5. **完成配对与数据回读**：核对 A/B 实际开局及固定条件，比较问题对应指标、原生结果和触觉质量；必要时在剩余预算内补无调整重跑。检查视频解码、因果样本读取、成功示范视图和错误动作采纳标记，保留无改善或不确定的结论。
6. **按交付分别报告并停止**：给出可复现入口与配置、数据清单、样本、媒体/日志、验收结果及诊断对照材料；逐项标明已达成、未达成和确切阻塞。两项交付齐备或任一预算耗尽即停止，再依据结果讨论三方向放量与后续训练。

交接材料应能回答两个独立问题：合格示范能否用于后续 TacJev 训练消费；Agent 的诊断依据、后续选择及其实际效果是否可检查。当前阶段不要求训练学生，也不以回放或教师成功代替学生成功。

## 3. 动作输出、解释器与控制来源

**新的单臂模型输出**是且仅是一个 token：`MV_FWD`、`MV_BACK`、`MV_LEFT`、`MV_RIGHT`、`MV_UP`、`MV_DOWN`、`GRASP`、`RELEASE`、`DONE`。六个 `MV_*` 沿本体定义的基座坐标方向移动固定步长；`GRASP/RELEASE` 设置夹爪二值目标并保持若干控制步；`DONE` 结束决策循环，不产生机械臂动作，也不能自动算作任务成功。解释器需要按本体固定方向、步长、工作空间边界、夹爪实际开度、保持步数和底层控制率。可选旋转 token 与双臂 `STILL` 在新参考中只是扩展，不属于已确定的九 token 单臂合同。

一条可用于蒸馏的决策样本应是 `当前模型可见观测 → 在线教师 token → 解释器执行区间 → 新观测/任务信号`。一个 token 可以跨多个仿真控制帧，因此**决策步、物理帧和训练样本不能默认一一对应**。必须记录 token 到实际连续动作/帧区间的映射。历史逐帧连续动作数据不能仅改字段名就当作 GPT-6 元动作示范；如要转换，须定义可复核的离散化规则并标明非在线教师来源。

**首任务的动作与目标条件**：ViTaForge 的 `lift_can` 实际指令为把侧倒罐子转为直立，成功谓词包含物体姿态，不能仅凭任务名判断六方向平移足够。Arena `lift_object` 的原生成功要求方块距采样目标位置小于 5 cm，不只是抬高；现有成功教师使用连续旋转保持向下姿态。新元动作路径必须明确姿态保持由谁完成，并实际验证词表能否完成任务。检查历史成功 run `20261005T130903-428292` 的原始 `agentview` 第 0、169、206 帧未见清楚可识别的目标 marker；成功帧的方块/末端已超出该场景相机画面，历史任务文字为 `null`。这些样本不能证明目标可见性；需验证新教师实际收到的视角、目标表示和完整任务文字。上述检查不改变 benchmark 原生成功规则。

**历史验收，已退出候选**：RoboSynChallenge `mixer_operating` 曾以源动作接触重定向执行 Isaac/PhysX 迁移，使用 `robosyn_dual_joint_position` 14D，取得 316 帧双臂四指 RTX 触觉审计通过的 P0 收据。原 DexSim 引擎未启动。该收据、数据集和视频保留供审计；不再为 GPT-6 → TacJev 采集、蒸馏或双臂词表规划选取 RoboSyn。

前两行与 RoboSyn 历史 run 构成 2026-10-05 **三来源触觉采集 P0**；Isaac Manipulation 是此后的独立新增方向，不能并入旧验收数。论文/新参考所说的 **六 benchmark GPT-6 rollout** 是整体方案范围，列有 LIBERO、RoboLab、RLBench、LeHome、UniVTAC、IsaacLab；ViTaForge 与 UniVTAC 的任务/适配器映射仍需确认，Arena 与 Isaac Manipulation 是 IsaacLab 家族下不同集成轨，RoboSynChallenge 不在该六项中。`isaac_manipulation` DataEngine corpus alias 目前仍独立于 `isaaclab`，不凭运行时家族推断两份语料同源。旧网页的“3 benchmark、20 开局”是 9 月试跑口径，不能作为 10 月 7 日六项放量的数量承诺。

## 4. 成功验收标准（按阶段）

1. **场景与任务绑定**：固定开局、机器人/TacClaw 资产、传感器身份、任务说明、控制语义、reset/终止和 benchmark 原生成功规则；场景检查与交互检查有记录。原生任务信号是最后裁判，GPT 或 TacJev 输出 `DONE` 只是停止意图。
2. **单次 rollout 留证**：每次尝试无论任务成功、失败或中断，保留可解码视频、逐帧 RGB/触觉/state/实际 action、日志、原始任务结果和失败原因。在线教师运行另须保存每轮实际请求/响应、输入与动作归属、token→连续控制映射及哈希；没有这些不能标成 GPT-6 在线 rollout。
3. **触觉与数据可用**：独立验证时钟/帧数/字段、接触与无接触行为、压深保真、原生任务成功、输入和媒体哈希；DataEngine 发布可回读的数据集 manifest，并保留所有失败 episode 供诊断。作为**成功示范的正标签**还要求原生任务和触觉质量通过；失败轨迹不能直接混入正示范。论文还要求来源、重定向和场景回放证据。
4. **训练可用**：样本按决策前实际可见观测配下一 token，防止看到动作结果；按 episode 划分训练/校准/测试。训练报告应记录数据与配置、优化步数、有限 loss、checkpoint 可重载、动作词表及解释器版本。三来源现有连续动作 BC 通过的是训练链冒烟，不满足 TacJev 离散蒸馏验收。
5. **学生在线评测与进化**：固定任务/seed/预算和解释器，TacJev 独立从新鲜 RGB/触觉观测闭环选择动作；服务记录时延、超时、触觉健康和预测收据；报告原生任务成功、失败类别、视频与逐步轨迹。候选与当前模型在相同条件下比较，并检查旧任务退化，达门槛才提升版本。论文给的是评测方式，**具体成功率、样本量、退化容忍度和统计门槛均未定**。单条演示或训练集 loss 不能证明泛化/自进化。

已有三来源 P0 独立收据确认任务、触觉、媒体、DataEngine 回读和 BC 冒烟均通过；历史 42 次尝试视频均可解码。该收据明确排除“学得策略原生成功/泛化”和“RoboSyn 原 DexSim 运行”。论文中的另一个 LIBERO ACT 实验是独立案例，不能替代这三来源或 TacJev 的验收。

## 5. 未定事项

1. **可见输入的实现与预检**：用户已选“3 图+完整任务+最近最多五个 `MV_*`”，末端状态、力值和物体坐标不进入首版模型输入；相机范围、原生目标呈现、触觉拼图/预处理版本和缺失传感器处理仍需实际验证。
2. **模型实现**：TacJev 的具体多模态骨干/初始权重、图像预处理、候选 token 打分实现、交叉熵到概率校准的切换条件、损失权重 `λ` 与温度校准规模未指定。
3. **元动作解释器**：用户已选九 token 与明示的固定朝下姿态保持；基座轴向、米制步长、执行控制步数、碰撞与工作空间限制、抓放开度/保持及终止接口尚需校准和冻结。Arena 原生控制率为 50 Hz，默认物理预算为 5 秒/250 控制步；模型网络等待的墙钟和物理时间须分别记账。论文其他双臂 benchmark 的词表与同步语义另行确定；不以 RoboSyn 作为规划对象。
4. **旧数据去向**：现有连续动作示范是预训练、比较基线还是经过明示转换后进入 TacJev 数据集？转换准确性与源类型标签需先定；不能直接改名复用。Isaac Manipulation PI0.5 路线是独立连续动作 VLA 接线验收，不能当作 TacJev 离散教师。RoboSyn 历史数据不进入本轮候选集。
5. **六 benchmark 放量清单**：每项固定任务、开局/seed 数、预算、TacClaw 适配成熟度以及 ViTaForge/Arena 与 UniVTAC/IsaacLab 的确切映射仍未定；RoboSyn 已明确排除。
6. **数据格式、后续训练和放量门槛**：旧网页计划导出 LeRobot v3；新 token 决策样本与逐帧控制数据如何在该格式中对齐尚未冻结。首批默认正示范视图与错误动作排除规则已确认，失败轨迹用于其他训练的方式、TacJev 持出成功率/动作准确率/校准阈值、旧任务回归容忍度、触觉贡献对照与重复次数仍未定。首批六次原生尝试/300 次推理请求/两小时上限不是放量指标；旧 20 开局试跑的“成功率统计无门槛”不自动延续到新阶段。
